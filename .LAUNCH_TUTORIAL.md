```

└───────────────────────────────┴───────────────────────────────┴───────────────────────────────┘
```

### 🔹 Terminal 1: Launch the Python LSTM ML Inference Server
```powershell
# Windows PowerShell
.\.venv-ml\Scripts\python.exe ml\inference_api.py
```
* **Success Output:** `Serving forecast API on http://127.0.0.1:8787`
* *Purpose:* Powers the real-time LSTM Neural Network monthly tonnage forecast and CENRO expense budget projections.

---

### 🔹 Terminal 2: Launch the Web & Mobile Frontend Server
```powershell
npm run web
```
* **Success Output:** `Web is waiting on http://localhost:8081`

Keep this terminal open for live seeding and clean database wipes during the defense:
```powershell
npm run db:seed
```
* *Purpose:* Instantly seeds the master CICTO account, 21 Danao City barangays, souvenir rewards catalog, municipal trucks, and AI dispatch settings in **3 seconds**.

## 4. AI & Machine Learning Execution Guide

The `ml/` directory contains the complete Python machine learning pipeline:

```
ml/
├── data/
│   └── block_a_monthly_m3.csv       # Historical 46-month Danao City waste series
├── train_lstm.py                    # TensorFlow LSTM training pipeline
├── evaluate_stability.py            # Multi-seed stability & baseline evaluator
├── inference_api.py                 # Multi-threaded HTTP inference server (:8787)
└── monitor_and_retrain.py           # Drift detection and auto-retraining monitor
```

### 1. Retrain the LSTM Model from Scratch:
```powershell
.\.venv-ml\Scripts\python.exe ml\train_lstm.py --epochs 300
```
* **Output:** Generates `output/ml/danao_block_a_lstm.keras`, `metrics.json`, and `scaler.json`.

### 2. Run the 5-Seed Stability Evaluation:
```powershell
.\.venv-ml\Scripts\python.exe ml\evaluate_stability.py
```
* **Output:** Generates `output/ml/stability_report.json` comparing model ensemble stability across 5 random seeds against statistical baselines.

### 3. Start the Live Inference API:
```powershell
.\.venv-ml\Scripts\python.exe ml\inference_api.py
```
* **Test the endpoint in a browser:** Visit `http://127.0.0.1:8787/health` or `http://127.0.0.1:8787/model`.

## 5. Panel Q&A & Defense Talking Points

### 🎓 Q1: *"How does the system ensure security when database data is wiped?"*
> **Answer:** *"We implemented a two-tier governance architecture under CICTO oversight. First, our one-command CLI database seeder (`npm run db:seed`) uses the Firebase Admin SDK to cryptographically mint custom claims for the CICTO Super Admin and seed official Danao master data. Second, our frontend implements a self-healing profile hook: upon authenticating via Firebase Auth with official credentials, the Firestore master document is reconstructed on the fly with zero exposed passwords in client code."*

### 🎓 Q2: *"Why is the LSTM model superior to simple Linear Regression for Danao City?"*
> **Answer:** *"Solid waste generation in Danao City exhibits non-linear seasonal characteristics: spikes during September fiesta celebrations, rainy season vegetative surges, and holiday packaging peaks. Linear regression only estimates a straight monotonic trend, whereas our LSTM recurrent neural network processes a 12-month lookback window to capture temporal lag relationships, delivering significantly lower MAE, RMSE, and MAPE errors."*

### 🎓 Q3: *"How does the Dynamic Route Optimizer handle Danao City's traffic choke points?"*
> **Answer:** *"The route optimizer integrates OSRM road network topology with a localized traffic congestion lookup table for known Danao bottlenecks (such as Beatriz D. Durano Ave commercial traffic, Duterte St Public Market congestion, and Camotes ferry port queues). It uses 2-Opt detour minimization to schedule pickups outside peak commuter rush hours."*

### 🎓 Q4: *"What prevents citizens from cheating the Eco-Reward tokens system?"*
> **Answer:** *"Token rewards are write-once and cryptographically bound to verified driver completion evidence (`reward_awards/report_{reportId}`). Redemptions are validated through backend transactions that verify sufficient balance and match exact approved catalog souvenirs, preventing double-spending."*
